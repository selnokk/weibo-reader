# Weibo Reader

Weibo Reader 是一款非官方 macOS 微博阅读工具。可以按用户集中查看发出和收到的评论，也能保存微博、提及该用户的内容，以及单条微博下的评论。保存后可以离线搜索和生成 HTML 报告，也可以订阅检查新评论。

[下载安装包](https://github.com/selnokk/weibo-reader/releases/latest) · [使用手册](./weibo_reader_user_guide.md)

当前安装包适用于 Apple Silicon Mac，需要 macOS 13.5 或更新版本。

本工具数据获取完全依赖于微博开放平台 CLI 服务。请使用自己的账号授权，接口调用可能消耗积分。
